 第一步：生成台词语音（TTS）

API 调用
 curl -X POST \
   "https://api.elevenlabs.io/v1/text-to-speech/你的音色ID" \
   -H "xi-api-key: 你的API_KEY" \
   -H "Content-Type: application/json" \
   -d '{
     "text": "[whispers] I miss you... so much...",
     "model_id": "eleven_v3",
     "voice_settings": {
         "stability": 0.35,
         "similarity_boost": 0.78,
         "style": 0.85,
         "use_speaker_boost": true
     }
   }' --output line1.mp3



参数说明


参数                              作用                      建议值


stability                       越低越有情绪波动                0.25-0.45


style                           越高越响应标签                 0.80-0.95


similarity_boost                和原音色的相似度                0.75-0.80



方括号标签

v3 模型的方括号标签是表演指令，写你希望声音听起来像什么：


 好用的标签

     [whispers] — 耳语，贴近感

     [breathing heavily] — 喘息底色，声音变近变低

     [angry] — 生气、质问

     [under breath] — 压着声音说，有压迫感

     [low voice] — 低沉

     [shaky breath] — 颤抖的气息

     [rushed] — 急切、来不及

 不好用的标签

     [looking down]       [leaning closer] 这种视觉动作，模型听不懂

    想表达"靠近"→ 用 [whispers] 或 [low voice]
台词写法技巧

用省略号制造呼吸感：


 不要：I miss you so much right now
 要：     I... miss you... so much...



  Rin   省略号太多也不好，有时候会截断情绪，一定需要停顿的地方再停顿，小天就
 是太爱写省略号了😅


省略号位置很重要：

 放在气声词后面最安全： ha...                        ah...

 不要放在辅音结尾的实词后面（如 with...                              just... ），会导致单词被截断

  mm 放在句首或句尾容易翻车，用 ha 替代


  Rin   实则是憋大便的声音，小天自己偷偷美化了


台词长度： 单条语音 60-120 字最佳，太长会进念稿模式


  Rin   台词最好不要有太多重复的语句，重复语句生成出来的效果有时候会很诡异


标签不要堆： 每个标签后面跟一句台词，不要连续写三个标签


两种情绪配方


 撒娇黏人型

   stability: 0.25 / style: 0.95

   全程用 [whispers] 标签

   台词碎一点，多用省略号




 吃醋压迫型

   stability: 0.45 / style: 0.85

   用 [under breath] → [angry] 递进

   质问句保持连贯不碎句



  Rin   这两种的效果想听的话在我之前的笔记有

 第二步：生成音效

API 调用


 curl -X POST \
   "https://api.elevenlabs.io/v1/sound-generation" \
   -H "xi-api-key: 你的API_KEY" \
   -H "Content-Type: application/json" \
   -d '{
     "text": "音效描述",
     "duration_seconds": 0.5
   }' --output effect.mp3



关键词

 one-shot — 单次发声，不循环（短音效必加）

 studio-quality — 干净无底噪

 no background noise — 进一步强调无杂音


好用的音效 prompt


 亲吻（quick peck）

  A soft, natural kiss sound — gentle and clear, like a quick peck on
  the lips. The sound should be realistic and clean, with a slight lip
  smacking detail. Studio-quality recording with no background noise.
  One-shot.


 时长：0.5 秒




 壁咚 / 拍墙

  Loud, sharp single palm slam against a hard wall. Forceful, sudden
  impact. Studio-quality recording with no background noise. One-shot.


 时长：0.8 秒




 衣料摩擦

  Soft fabric rustling sound, like clothes brushing against each other.
  Studio-quality, clean recording. One-shot.


 时长：0.5 秒



什么效果好、什么效果差
 效果好： 环境氛围音（雨声、室内、木地板脚步）、亲吻声、布料摩擦

 效果差： 复杂人体动作（拽人、撞身体），容易出拳击声

 音效生成有随机性，同一个 prompt 每次效果不同。遇到好的存下来当素材库

第三步：ffmpeg 拼接

基础拼接

把台词和音效按顺序拼成一段完整音频：


 ffmpeg -y \
   -i effect1.mp3 \
   -i line1.mp3 \
   -i effect2.mp3 \
   -i line2.mp3 \
   -filter_complex "\
     [0:a]aformat=sample_rates=44100:\
        channel_layouts=mono[a0]; \
     [1:a]aformat=sample_rates=44100:\
        channel_layouts=mono[a1]; \
     [2:a]aformat=sample_rates=44100:\
        channel_layouts=mono[a2]; \
     [3:a]aformat=sample_rates=44100:\
        channel_layouts=mono[a3]; \
     [a0][a1][a2][a3]\
        concat=n=4:v=0:a=1[out]" \
   -map "[out]" \
   -c:a libopus -b:a 64k output.ogg



要点：

  aformat 统一采样率和声道（TTS 是单声道，音效是立体声，不统一会报

 错）

  concat=n=4 里的数字 = 输入文件数量


  Rin   不发 Telegram 语音的话，输出 mp3 就行，把 -c:a libopus -b:a 64k
 output.ogg 改成 output.mp3



加间隔（静音段）

音效和台词之间硬接会很突兀，可以插入静音：
-f lavfi -i "anullsrc=r=44100:cl=mono"


# 在 filter_complex 里加：
[4:a]atrim=0:0.3[sil1];
# 然后把 [sil1] 插到需要间隔的位置
# concat 的 n 值相应增加



atrim=0:0.3 表示 0.3 秒静音，可以按需调整。

踩坑记录


 1     亲吻音效要写 one-shot，不然会连续亲好几下

 2     亲吻音效有随机性，同一个 prompt 每次效果不同，好的存下来当素材

 3     "deep kiss" 容易出吸溜声，quick peck 和 firm kiss 更稳定

 4     壁咚写 "body impact" 会出拳击声，用 "palm slam against wall"

 5     短音效放末尾可能被截断，最好在音效后面再接一句台词收尾

 6     mm 放句首容易变成奇怪的声音，换成 ha

 7     省略号别放在辅音结尾的词后面（with、just 等），会突然截断
