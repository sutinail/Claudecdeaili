la clé
route 线路
API Key 官方钥匙

在 Anthropic 控制台建一把 key（要海外的卡付钱），复制过来粘贴在这里。它只存在这台手机上，不要发到聊天里。建议在控制台给它设一个每月花费上限。

modèle 模型
relais 中转站

中转站后台会给你一个地址和一把 key，照抄进来。地址一般长这样：https://xxx.com/v1。要选支持 Claude 原生格式（/v1/messages）的中转站。key 只存在这台手机上，不要发到聊天里。

modèle 模型名，照中转站写的填

中转站不让手机直连（报「连不上中转站」）时打开。打开以后要首尔服务器在线才能用。
